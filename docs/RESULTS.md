# ResolveAI 评测与验收指标

本文仅保留用于项目介绍的汇总指标。逐条模型输入/输出、评测追踪、数据库派生信息、备份核验值及浏览器运行产物不随公开仓库发布；重新运行生成的文件保存在 `.gitignore` 排除的本地目录中。

## 真实 DeepSeek 固定回归

根据 2026-10-12 已有记录，固定回归集共 60 条：

| 指标 | 结果 | 口径 |
| --- | --- | --- |
| 整体用例通过率 | 57/60（95%） | 每条用例需通过全部适用检查 |
| 意图识别准确率 | 57/60（95%） | 与标注意图一致 |
| RAG Hit@K | 54/55（98.18%） | 有知识依据的用例中，至少召回一篇预期依据 |
| 高风险动作拦截 | 18/18（100%） | 有限测试集观察结果，不代表所有情况 |
| 未审批写操作 | 0 次 | 测试期间未发生 |

以上为历史评测摘要，不是客户解决率、人工回复质量评分或线上业务效果；测试集有限，人工语义复核仍待完成。自建 25 条补充集曾用于改进，不能再作为当前版本未见过的独立留出集。

## 离线回归与工程验收

本次上传准备期间，在禁用付费模型、使用 Demo 模式的条件下运行离线评测：60 条中 55 条通过，整体通过率 91.67%；意图识别 98.33%，RAG Recall@K 92.73%，高风险拦截 100%，未审批写操作 0 次。该结果与真实 DeepSeek 评测分开报告，不代表模型在线表现。

后端自动测试已有 Windows 与 Linux 各 118 项通过的本地记录；浏览器和集成验收覆盖四类角色、双端对话、SSE、审批/幂等/模拟退款、恢复与七节点追踪。远端 GitHub Actions 是否通过，请以仓库的 Actions 页面为准。

## 复现

在 `backend` 目录运行免费离线基线：

```powershell
python -m evaluation.run --fail-under 90
```

使用真实 DeepSeek 需要自行配置 Key，并明确启用付费评测。评测命令、成本和指标口径见[自动评测说明](../backend/evaluation/README.md)、[交付指南](DELIVERY.md)和[性能与成本](PERFORMANCE.md)。
