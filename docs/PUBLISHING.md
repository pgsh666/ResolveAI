# 发布范围与安全说明

整理日期：2026-10-13。本仓库是从本地开发项目独立复制、检查后准备上传的版本；整理过程不修改原项目，不迁移业务数据库，不启动或重启原服务。

## 包含与不包含的内容

- 包含：前后端源码、MCP 服务、迁移、测试、评测用例、配置模板、启动/验收脚本、文档、前端使用的静态资源，以及[整理后的指标汇总](RESULTS.md)。
- 不包含：实际 `.env` / `.env.auth`、Cookie、访问令牌、数据库文件、备份、数据库派生行数/摘要/校验值、逐条模型评测记录、验收运行产物、模型权重、node_modules、构建缓存、临时 PDF、浏览器录像与调试压缩包。
- 汇总指标保留适用范围和测试集限制；历史 v2、初始基线和待填人工复核模板不会描述为当前新增成绩。
- 前端头像与卡通静态资源随源码保留；公开发布前仍应由项目负责人确认这些素材是否适合对外分发。本仓库没有自动替第三方素材授予许可。

## 发布整理做了哪些修改

1. 加强 `.gitignore`：环境配置、备份、缓存和全部本地评测/验收输出默认忽略。
2. 公开仓库只保留汇总指标，不包含逐条日志、数据库派生信息、备份核验值或未发布录像。
3. 两个服务联测脚本使用 PATH 中的 `docker`，不依赖开发者的 Windows 安装绝对路径；仍支持 `--docker` 指定其他可执行文件。
4. 评测说明使用项目相对目录；PyCharm 运行配置的模块名与 ResolveAI 仓库目录对齐，解释器仍由使用者选择。
5. 使用 `.gitattributes` 统一 Git 中的文本换行，并清理文件末尾多余空行；Windows 启动批处理保持 CRLF，图像按二进制保存。不修改业务逻辑或测试用例内容。

这些修改不代表重新运行付费模型评测、重新完成浏览器验收或成功运行远端 CI。汇总数值的来源和限制见[指标汇总](RESULTS.md)。

## 拉取后的初始化

按[交付指南](DELIVERY.md)准备 Docker、语义模型和私密账号，再启动服务。默认 Demo 不消耗模型额度；真实 DeepSeek 需要使用自己的 Key，真实评测另有显式付费许可。

同一机器有正在运行的原项目时，不要直接复用端口或 Compose 项目/数据卷。若使用独立验收配置，也要先确认 3001、8002、8003 等验收端口没有被另一套服务占用。

不公开真实密码、个人邮箱、Cookie、CSRF、审批凭证或数据库备份。GitHub 推送认证应使用本机浏览器/Git Credential Manager，不把令牌写入仓库地址、脚本或文档。

依赖漏洞数量和模型表现是当时版本的验证结果，不是未来自动保证；独立人工语义复核、真实业务接口和正式公网部署仍未完成。
